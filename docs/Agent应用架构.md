"""Agent 应用架构（切片路线）：阶段闸门 + AI 决策 + 自检

这份文档回答一个问题：**整条生产线能不能自动化成一个 Agent 应用？**
能，但要先把「机器干不了的那一步」单独摘出来，不能一条命令跑到底。

    脚本 → 分镜 → 素材需求清单 ──┐
                                │  ← 这里必须停：人工剪影视素材（唯一必须人工的环节）
                                ↓
        素材导入 → AI 排镜头(EDL) → 渲染 → 自检 → 成片

## 一、三层分工（谁干什么，边界在哪）

| 层 | 谁来做 | 干什么 | 为什么不能换 |
|---|---|---|---|
| 判断层 | **LLM** | 需求清单要什么镜头、剪辑用什么手法、哪里打大字/人名条 | 这些是创作意图，规则写不出来 |
| 执行层 | **代码** | 编码、拼接、贴语音、烧字幕、混 BGM、合规校验 | 确定性的活，交给 AI 只会引入幻觉 |
| 证据层 | **代码** | 时长/画幅/音轨/占比/槽位对账、素材出处清单 | 「干完了」必须能被验证，不许口头汇报 |

反面教训（两个都真实踩过）：
- 让规则去猜创作意图 → 把每个分镜都标成「必须」，优先级等于没有。
- 让 AI 去干确定性的活 → 它会编出不存在的素材 id、把时长排错。

## 二、阶段闸门

    run.bat agent                        # 看现在卡在哪、下一步敲什么（唯一交接点）
    run.bat agent --stage 1 -t "题材"     # 出脚本 + 分镜 + 素材需求清单，然后停下
    python scripts\import_clip.py ...    # 人工：按清单剪素材并绑槽位
    run.bat agent --stage 2              # AI 排镜头 → 渲染 → 自检 → 出成片

阶段 2 有条**故意不自动化**的东西：**绝不重写字稿**。
脚本在阶段 1 已经给你看过、你也照着它剪了素材；阶段 2 再「顺手优化一下」
就是背刺 —— 剪好的素材对不上新稿。时长跑出区间只告警，改不改由你决定。

## 三、AI 决策点（只有三处，都可降级）

1. **需求清单**（`needs.py`）：一段旁白要找什么样的镜头、涉及谁、屏幕上打哪 2-4 个字。
2. **剪辑导演**（`edl.py::direct_edl`）：排镜头序列 —— 哪条素材、从第几秒取、取多久、
   什么手法、要不要在同一场的第 2 段换手法。它只看得见「手头真有的素材」，不能编 id。
3. **配图兜底**（`images.py`）：没找到影视素材的分镜，按回退方案出生成图/图库图。

三处都有**规则兜底**且异常不阻断出片：LLM 挂了就走规则排镜头，宁可不好看也要能出片。

## 四、剪辑手法（`shotvideo.py` + `frames.py`）

| 手法 | 怎么实现 | 适合什么时候 |
|---|---|---|
| `plain` | 素材直铺，不加位移（素材本身就在动） | 交代环境、过场 |
| `slow_push` | 画布放大 `motion_scale` 倍后按 `motion_expr` 缓慢平移裁切 | 想强调、放慢节奏 |
| `freeze_zoom` | **抽一帧 → 裁一块放大 → 当静态图走原来的静态图路径** | 旁白说到某个瞬间/细节 |
| `still_pan` | 静态图 + 缓移（回退画面用） | 没素材的分镜 |

`freeze_zoom` 那个取巧是全案能低成本落地的关键：**不写任何 zoompan 滤镜**，
直接复用已有的静态图编码链路，还白捡原有的缓动。

画面元素（`media.draw_callout` / `draw_nametag`）：大字标注 + 人名条，
版面分区固定、按像素验收（`frames.ink_band`），不许互相侵入。

竖屏放横屏素材默认 **blurpad**（完整画面居中 + 上下模糊衬底）而不是硬裁：
16:9 进 9:16 硬裁只剩中间 32% 宽度，人物很容易被裁掉。

## 五、自检与举证（每个阶段都不能只靠「我觉得」）

- 剪辑表出片前必须过 `edl.validate_edl`：单段 ≤ `clips.max_seconds`（**只管切片**）、
  切片占比 ≤ `clips.max_share`、镜头总长 = 画面时长、素材 id 在库、取用区间不越界。
- 出片后 `agent._selfcheck`：文件存在、时长覆盖正文、画幅正确、有音轨。
- `agent._source_report`：**素材出处清单**（片名/年份/人物/占比/用在哪些分镜），
  发布举证用。
- 零 API 冒烟 `scripts/smoke_clips.py`：合成假素材把整条剪辑链路钉死（30 项）。

## 六、已知边界（不要假装没有）

- 素材必须**人工剪**：v1 不做自动视频索引，这是有意为之（见 v1 计划文档）。
- 一个分镜只剪 1 段也能成片：渲染时取这段的不同段落铺满，观感不如多剪几段。
- 切片占比会随「有素材的分镜数」上升，超 45% 直接拒绝出片 —— 这是合规红线，
  不是可以调优的阈值。
- 同一场戏的多个镜头用同一条素材（不同 src_in），观众能看出是同一段；
  想避免就多剪几段绑同一场的其他槽位。
