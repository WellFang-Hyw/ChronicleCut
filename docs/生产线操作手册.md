# 生产线操作手册（每期照着走）

> **这份文档是什么**：一条视频从「选题」到「出成片」的**操作顺序 + 每步的判据 + 踩过的坑**。
> 每期开工照着往下走就行，不用回头翻代码。
>
> **跟 README 的分工**：README §3.8 讲**为什么这么设计**（为什么要阶段闸门、为什么阶段 2 不重写字稿），
> 本文只讲**怎么操作**。代码实现见 `docs/Agent应用架构.md`。

---

## 0. 开工前 30 秒自查（零成本、不调 API）

```bat
run.bat agent
```

看三件事：

| 看什么 | 说明 |
|---|---|
| **素材库几条** | 0 条 = 这期不会有影视切片，画面全走 AI 生成图/静态图。先剪素材才有切片 |
| **脚本几份** | 多份时它会摊开清单，标出「▶ 最新，就是它」—— 阶段 2 默认用最新那份 |
| **卡在哪一步** | 它会直接告诉你下一步敲什么命令 |

同时可以看一期系列进度（哪几集出过、下一集是哪集）：

```bat
run.bat series "古代十大权臣"
```

## 1. 整体顺序（阶段闸门）

```
第 0 步  定选题（两级：故事类型 L1 + 标题/描述 L2）
   ↓
第 1 步  run.bat agent --stage 1 …      出脚本 + 分镜 + 素材需求清单   ← 跑完**主动停下**
   ↓
   ── 人工：按清单剪素材 → import_clip.py 绑槽位 ──   ← 整条链里唯一必须人工的一环
   ↓
第 2 步  run.bat agent --stage 2 …      AI 排镜头 → 合规校验 → 渲染 → 自检   ← 全自动
   ↓
第 3 步  验收：成片 / 剪辑表 / 素材出处清单
```

**为什么顺序不能反**（三条硬约束）：

1. **清单必须在剪素材之前独立产出**——素材是绑在**槽位号**（`s01_sh1`）上的，槽位号由阶段 1 生成。先剪后出清单 = 白剪。
2. **阶段 2 绝不重写字稿**——你是照着阶段 1 的稿剪的素材，它再「顺手优化」就是背刺你。时长跑出区间只告警，改不改由你定。
3. **配音之前先剪**——阶段 1 没配音，清单里的秒数全是**估算**（`duration_source: estimated`，按 4.7 字/秒算）。所以按 6–8 秒剪就行，**别卡到 0.1 秒**；导入后阶段 2 会按真实语音重算。

## 2. 第 0 步 · 定选题（两级）

选题是**两级**的：L1 = 故事类型（受控词表，15 类）；L2 = 详细标题 + 与故事相关性最高的描述。

```bat
run.bat topics                        :: 看整个选题池（含系列条目；类型写错会列出全部可选值）
run.bat -t "标题"                                       :: 按池子里的标题跑（两级池子自带）
run.bat -t "标题" --topic-type "行旅与驿传" --topic-desc "…"  :: 自己制定两级（类型受控）
run.bat --type "行旅与驿传"                              :: 不带 -t：只在某一类里挑
```

**系列片**（有顺序的成套选题）走另一条路——系列条目**不进随机池**，只能按集号取：

```bat
run.bat series "古代十大权臣"                                   :: 看进度 + 下一集是哪一集
python scripts\add_topic.py --series "古代十大权臣" --series-desc "这个系列讲什么" ^
       --ep 1 --type "政变与权力" --title "…" --desc "…"        :: 建一集
run.bat agent --stage 1 --series "古代十大权臣"                  :: 直接出系列下一集的稿
```

规矩：集号必须连续、不重复（同集号会被拦下，退出码 2）；成片与封面顶上的小字会显示「栏目 · 系列名 第N集」。

## 3. 第 1 步 · 出脚本 + 素材需求清单（跑完会停下）

```bat
run.bat agent --stage 1 --series "古代十大权臣"                    :: 系列
run.bat agent --stage 1 -t "标题" --topic-type "…" --topic-desc "…"  :: 单集
```

产物：

```
data\output\<日期>_plan_<标题>_脚本.md          字稿（读这份，逐段核对史实）
data\output\<日期>_plan_<标题>_metadata.json    机器读数（别手改）
data\needs\<日期>_<题材>_素材需求.md            ← **照这份剪素材**（取景单也在这份里）
data\needs\<日期>_<题材>_素材需求.json
data\needs\<日期>_<题材>_取景单.json            （取景单的机器版）
```

#### 取景单：去哪儿找这些画面（就在「素材需求.md」里）

清单第二节是**取景单**，针对每个「必须剪」的槽位给出：

- **候选片源**：模型给的可能有这场戏的剧（含主演/平台锚点）。**一律未核实** ——
  模型**连剧名都会编**（实测编出过不存在的剧还标高置信度），所以「以你能不能搜到为准」。
- **推算的集数位置**：每部候选给「**第 X–Y 集**」+「全剧进度 %」+「集内位置（前段/中段/集尾）」
  + 「推算依据」。读法：
  · 这是**推算的参考值，不是查证结果**，偏 1–3 集很正常 → 找不到就往前后各推 1–2 集；
  · 进度 % 是代码算的（不让模型算数），集数与总集数矛盾时表里会标出来；
  · 标了「**区间过宽（≥15 集）**」的 = 这处是「哪部剧都有」的通用镜头（朝堂/宫门空镜），
    **别照区间翻**，直接在素材库里找任意同年代空镜；
  · **分钟级时间码不会给**（模型给不准，纯编造）；
  · 表里已经剔掉「**这部剧主线拍不到这场戏**」的候选（如把汉武帝驾崩后十几年的事
    推荐给「讲汉武帝一生」的剧），留下的仍以你能搜到为准；
  · 候选是**多轮累积**的：模型每轮给的都不一样，所以**多跑几次 `--stage sources`
    候选会越攒越全**（不会互相覆盖）；标了「自检：不确信存在」的排最后。
- **集内位置只有分段词**（前段/中段/集尾），没有「第 12 分 30 秒」这种东西。
- **检索式**：可以复制去 B 站/YouTube 搜的词（代码生成，例 `汉武大帝 托孤`）。
  **这是主力手段** —— 搜一下那场戏通常就在结果里，比先查集数再拖进度条快得多。
- **回填栏 + 预填好的导入命令**：找到了就把「片源/集数/起止时间」记在那一行，
  命令里的槽位已经填好了，只改前面几项。

> 想换一批候选：`run.bat agent --stage sources`（只刷新取景单，
> **不会**动你已经看过的清单描述）。

清单怎么读（**两级粒度别混**）：

- 清单按**槽位**给需求（`s04_sh1` = 第 4 分镜第 1 段），槽位是按「单个片段」切的：
  一个 26 秒的分镜 / 单段槽位上限 8.5 秒（`needs.slot_seconds`）→ 切 3–4 段。
- 但**每个分镜只有第 1 段要真剪**，第 2 段起标「↺ 复用本场素材」。
- 所以一期通常只剪**几条到十几条**，不是几十条。优先级（★必须剪）只落在**章节开场**，且只标第 1 段。

判据：命令最后会打印「槽位 N 个，铺满画面需 X 秒；**真要剪的约 Y 秒**」和「关键位置 N 条」。

## 4. 第 2 步 · 剪素材并导入（唯一必须人工的一步）

### 4.1 剪之前先确认硬线

| 项 | 要求 | 为什么 |
|---|---|---|
| 单段时长 | **≤ 10 秒** | 合规：短段更像「引用」，长段更像「搬运」 |
| 切片总占比 | **≤ 成片的 45%** | 同上，超了**直接拒绝出片**（不会出个错的） |
| 音轨 | **必须没有**（导入强制去） | 不用原声，我们有自己的配音 |
| 画幅 | 1920x1080 / 30fps（导入自动转） | 拼接要参数一致 |
| 来源字段 | `--title` / `--year` / `--people` 必填 | 发布前出「素材出处清单」举证 |

> 两个时长数字别混：**8.5 秒**是清单里槽位的切分上限（`needs.slot_seconds`，内部用）；
> **10 秒**是素材单段的合规红线（`clips.max_seconds`，超了校验不通过）。
> 所以清单让你剪 6–8 秒，是安全的。

### 4.2 导入并绑槽位

```bat
python scripts\import_clip.py --file "D:\你的片段\hg_01.mp4" --id hg_01 ^
    --title "汉武大帝" --year 2005 --people 霍光,汉武帝 --era 西汉 ^
    --slots s01_sh1,s01_sh2,s01_sh3,s01_sh4 --in 12:30 --out 12:37
```

要点：

- **一条素材可以绑同场的所有槽位**（上面 4 个槽位一条素材就填满了）——这是「剪几条就够」的关键。
- 剪得快可以加 `--preset ultrafast`（批量导入提速；生产默认 medium）。
- 同 id 重导要加 `--force`；撤销用 `--remove <id>`；体检用 `--check`。

### 4.3 看覆盖度（零成本）

```bat
run.bat agent
```

覆盖度从「还缺 N（关键 M）」变成「已绑定 N」就对了。**没剪完也能出片**——没绑素材的分镜走回退画面（AI 生成图），只是少了切片的质感。

> ⚠️ 找不到人物镜头（古代题材很常见）不用硬凑：跳过它，那块走 AI 生成图兜底。
> 优先剪**朝堂/宫门/街市/送葬**这类全景氛围镜头——最好找、也最好用。

## 5. 第 3 步 · 出片（全自动）

```bat
run.bat agent --stage 2 --metadata "data\output\<日期>_plan_<标题>_metadata.json"
```

`--metadata` **建议一直带上**。不带也能跑（默认挑最新的 plan 产物），但 `data\output` 下有多个脚本副本时，带上它就是显式钉住，不会挑错。

它会打印「脚本：<文件名>」和「这一期：<系列/集号/题材>」——**先扫一眼这两行再让它跑**，确认是你这次要出的那一期。

流程：补齐语音/配图 → AI 导演排镜头（EDL）→ 合规校验 → 渲染横竖双版 + 封面 → 自检报告 + 素材出处清单。

## 6. 第 4 步 · 验收

```bat
run.bat agent                                :: 状态与产物路径
data\edl\<日期>_<标题>_EDL.json               :: 剪辑表：每镜用了哪条素材的哪一段、什么手法、多长
data\output\<日期>_<标题>_素材出处.md          :: 发布举证：用了谁的片子、什么时间码
data\output\<日期>_<标题>_横版.mp4 / _竖版.mp4
```

> 文件名里的「标题」不一定是同一个：`素材需求.md` 用的是**选题标题**（你池子里那条），
> `_EDL.json` / `_素材出处.md` / 成片用的是**成片标题**（模型写稿时拟的，EDL 那份截前 28 字）。
> 比如霍光这期：清单写「霍光：一个臣子凭什么能换掉皇帝？」，成片叫「霍光废帝：…」——
> **同一期，别当成两期**。

## 8. 出问题怎么办

| 现象 | 先查什么 |
|---|---|
| 阶段 2 出的是**另一期**的内容 | 看日志头两行「脚本 / 这一期」。默认取最新 plan；用 `--metadata` 显式钉住 |
| `data\output` 下脚本越堆越多，分不清 | `run.bat agent` 会摊开清单并标「▶ 最新，就是它」 |
| `x264 [error]: malloc of size … failed` / `Cannot allocate memory` | **环境**（本机 14GB 被 VS Code/浏览器吃到 90%+）。判据：隔离跑同一条也失败 + 代码路径当天没改 → 重跑或先关几个程序。冒烟可用 `run.bat smoke-clips --small` |
| 覆盖度一直是 0 | 素材绑的槽位号是不是这期的（槽位号来自本期清单，别用上一期的） |
| 切片占比报错、拒绝出片 | 切片总时长超过成片 45% → 少剪几条，或让更多分镜走 AI 生成图 |
| 「有 N 个分镜找不到语音缓存」 | 换过音色/语速。音频缓存 key = 文本 + 音色 + 语速，用 `--voice/--speed` 指定当初的值 |
| 想重出一版视频（稿子不动） | `run.bat agent --stage 2 --metadata "…"` 重跑即可，阶段 2 不重写字稿 |
| 取景单里的候选片源搜不到 | 正常 —— 候选是**未核实**的。直接用「检索式」搜；搜不到就跳过这处，走 AI 生成图兜底 |
| 想换一批候选片源 | `run.bat agent --stage sources`（只刷新取景单，不动清单描述） |

## 9. 一句话总纲

**该自动的全自动，该停的显式停住。** 机器干不了的那一步（剪素材）主动停下并说清「剪什么、剪几条、多长」；
剩下的（排镜头、剪辑手法、渲染、自检、举证）全自动跑完，并且每一步都交可验证的证据
（时长/画幅/音轨/占比/文件在不在），不许只说一句「完成了」。
